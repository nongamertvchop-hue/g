# เครื่องมือวิเคราะห์ข้อมูล — เรือนอักษร

สคริปต์ Python สำหรับดูว่า **ใคร ทำอะไร ที่ไหน อย่างไร เมื่อไหร่** บนเว็บ

## ต้องมีอะไรบ้าง

- Python 3.8 ขึ้นไป (ไม่ต้องติดตั้งไลบรารีเพิ่ม ใช้ของที่ติดมากับ Python)
- บัญชี **แอดมิน** ของเว็บ

## วิธีใช้

```bash
python analytics/analyze.py --user redmiss098
```

จะถามรหัสผ่านแบบซ่อนตัวอักษร แล้วพิมพ์รายงานออกมา

### ตัวเลือกเพิ่มเติม

| คำสั่ง | ความหมาย |
|---|---|
| `--days 30` | ย้อนหลัง 30 วัน (ค่าเริ่มต้น 7) |
| `--limit 500` | ดึงเหตุการณ์สูงสุดกี่รายการ |
| `--json report.json` | บันทึกผลเป็นไฟล์ JSON ไว้ใช้ต่อ |
| `--url https://...` | ชี้ไปเว็บอื่น (เช่นตอนทดสอบ) |

## รายงานมีอะไรบ้าง

1. **ภาพรวม** — จำนวนเหตุการณ์ ผู้ใช้ที่มีกิจกรรม ช่วงเวลาที่คึกคักที่สุด
2. **ทำอะไรบ้าง** — จัดอันดับการกระทำ พร้อมกราฟแท่ง
3. **ใช้อุปกรณ์อะไร** — มือถือ / แท็บเล็ต / คอมพิวเตอร์
4. **มาจากที่ไหน** — แยกตามประเทศ
5. **ใช้งานเวลาไหน** — กราฟ 24 ชั่วโมง (เวลาไทย)
6. **กิจกรรมรายวัน** — ดูแนวโน้มว่าเว็บโตขึ้นหรือเงียบลง
7. **ใครทำอะไรบ้าง** — รายบุคคล: จำนวนครั้ง รอบการใช้งาน อุปกรณ์ IP และช่วงเวลา
8. **สิ่งที่ควรตรวจสอบ** — ตรวจจับความผิดปกติอัตโนมัติ

## การตรวจจับความผิดปกติ

สคริปต์จะเตือนเมื่อพบ:

- ผู้ใช้ที่มีกิจกรรมสูงกว่าค่าเฉลี่ยเกิน 2.5 เท่าของส่วนเบี่ยงเบนมาตรฐาน (อาจเป็นบอท)
- ผู้ใช้คนเดียวเข้าจาก 3 IP ขึ้นไป (อาจมีการแชร์บัญชี)
- การกระทำล้มเหลวซ้ำ ๆ ของคนเดียวกัน
- การเข้าสู่ระบบล้มเหลวรวมตั้งแต่ 5 ครั้ง (อาจมีคนเดารหัสผ่าน)

> การนับ "รอบการใช้งาน" ใช้หลักเดียวกับเครื่องมือวิเคราะห์เว็บทั่วไป คือเว้นช่วงเกิน 30 นาทีนับเป็นรอบใหม่
